Animated stickers used by the "Will you go out with me?" and "I'm sorry" designs.

Source: Noto Animated Emoji by Google, https://googlefonts.github.io/noto-emoji-animation/
License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Credit is shown on the pages that use them.
They were resized to 160px with fewer frames so they load quickly on phones.
File names are the emoji's Unicode code points, e.g. 1f63b.webp is 😻.
To add one: download https://fonts.gstatic.com/s/e/notoemoji/latest/<code>/512.webp, shrink it, put it here,
and add the code to the STK list at the top of templates/ask.js.
